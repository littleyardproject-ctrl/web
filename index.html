為什麼小院子會開始做這件事？

小院子，是原築院建築延伸出的實驗型場域；專注於在地材料、工法，兒童友善的建築教育實踐。

串連在地建材共創價值，探索家的材料五感教育——這也是我們最主要的活動「家的材料課」。

我們不留下永久設施，而是把材料、故事與陪伴，留在一個又一個地方裡。

品牌故事

+
多年來，我們在建築設計的過程中，看見了無數不同的家庭、社區與地方。我們發現，真正影響一座城市的，不只是新的建築，而是人與人、人與地方之間是否還保有連結。好的建築可以改善空間，但真正讓地方持續成長的，是教育、文化、公益與共同參與。因此，我們開始思考：如果建築能創造空間，是否也能創造一個更好的地方？這，就是小院子的起點。

創辦理念

+
在每一次地方合作中，我們發現：企業希望投入 ESG，卻找不到真正能長期合作的地方；社區希望改善環境，卻缺乏持續的資源；學校希望帶給孩子更多元的學習體驗；地方品牌希望被更多人認識；居民希望重新找回對地方的認同。每一方都擁有改變地方的力量，只是彼此還沒有真正相遇——我們存在的目的，就是成為那個把彼此連結起來的平台。

Con+Create 的精神

+
CON + CREATE = TO CREATE TOGETHER，一起創造。我們相信，最好的公益，不是單向付出，而是共同創造新的價值——讓企業的品牌價值、居民的生活、孩子的教育、地方的文化，一起成長。

為什麼選擇地方創生

+
真正的地方創生，不是完成一個補助計畫，也不是一次性的活動。真正重要的，是建立一個十年後仍然持續發生的合作關係——讓地方不是被改變，而是被陪伴著，慢慢長出自己的樣子。

為什麼選擇教育

+
AI 可以回答問題，卻無法替孩子感受木頭的溫度；搜尋可以找到知識，卻無法替孩子理解家的故事。未來真正重要的能力，不是背更多答案，而是擁有觀察力、感受力、思考力、合作力、創造力與關懷力。我們教的不是建材，而是認識生活的方法。

為什麼相信「家」

+
每一個地方，都值得慢慢成為一個家。家不是一棟建築完工的那一刻，而是孩子放學後仍願意回來、居民願意主動相聚、企業願意一年一年再回來的地方。地方不是被改變，而是被陪伴。
